Git 필수 명령어 가이드 (초보팀장용)

1. 기본 협업 워크플로우 (자주 쓰는 3대장)

명령어 설명
git pull origin master GitHub 서버의 최신 코드를 내 컴퓨터로 가져오기 (작업 시작 전 필수)
git add . 모든 변경 및 추가된 파일을 장바구니(Staging)에 담기
git add 파일명 특정 파일만 지정해서 장바구니에 담기
git commit -m "메시지" 장바구니에 담긴 파일들의 저장 기록(버전) 남기기
git push origin master 내 컴퓨터의 커밋 내역을 GitHub 서버 master에 올리기

2. 브랜치(Branch) & PR 협업 관리

명령어 설명
git branch 현재 존재하는 브랜치 목록 확인
git checkout -b 브랜치명 새로운 브랜치를 만들고 즉시 해당 브랜치로 이동
git checkout 브랜치명 지정한 브랜치로 이동 (예: git checkout master)
git merge master 현재 내 브랜치에 master의 최신 코드를 합치기
git push origin 브랜치명 작업한 브랜치를 GitHub에 올리기 (이후 GitHub에서 PR 생성)

3. 상태 확인 및 오류 해결 (초기화)

명령어 설명
git status 현재 어떤 파일이 수정/추가/삭제되었는지 상태 확인
git log 지금까지 작성한 커밋(작업 이력) 목록 조회
git restore 파일명 내 컴퓨터에서 수정 중이던 파일의 변경 사항 취소 (원상복구)
git checkout . 저장하지 않은 현재 폴더의 모든 로컬 수정 내역 강제 초기화
git rm 파일명 파일 삭제 및 Git 관리 대상에서 제거
git rm -r . 현재 폴더 안의 모든 파일 및 하위 폴더 전체 삭제

💡 팀장용 실전 협업 팁

[팀원용 작업 루틴]

  1. git checkout master ➔ git pull origin master (최신 코드 수령)
  2. git checkout -b feature/내이름 (내 전용 브랜치 생성)
  3. 코드 수정 후 저장 ➔ git add . ➔ git commit -m "작업내용"
  4. git push origin feature/내이름 ➔ GitHub에서 PR 생성

[팀장용 검수 루틴]

  • GitHub Pull requests 탭 ➔ Files changed 코드 검수 ➔ Merge pull request 승인
  • 승인 후 내 VS Code에서 git pull origin master 실행하여 최신 상태 유지
