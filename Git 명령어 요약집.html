Git 필수 명령어 가이드 (초보팀장용)

1. 기본 협업 워크플로우 (자주 쓰는 3대장)

명령어 설명
git add . 모든 변경 및 추가된 파일을 장바구니에 담기
git add 파일명 특정 파일만 지정해서 장바구니에 담기
git commit -m "메시지" 장바구니에 담긴 파일들의 저장 기록(버전) 남기기
git push origin master 내 컴퓨터의 커밋 내역을 GitHub 서버에 올리기
git pull origin master GitHub 서버의 최신 코드를 내 컴퓨터로 가져오기 (작업 시작 전 필수)

2. 상태 확인 및 관리

명령어 설명
git status 현재 어떤 파일이 수정/추가/삭제되었는지 상태 확인
git log 지금까지 작성한 커밋(작업 이력) 목록 조회
git rm 파일명 파일 삭제 및 Git 관리 대상에서 제거
git rm -r . 현재 폴더 안의 모든 파일 및 하위 폴더 전체 삭제

3. 브랜치(Branch) 관리

명령어 설명
git branch 현재 존재하는 브랜치 목록 확인
git checkout -b 브랜치명 새로운 브랜치를 만들고 해당 브랜치로 이동
git checkout 브랜치명 지정한 브랜치로 이동
💡 팀장용 핵심 팁: 매일 작업 시작 전에는 항상 git pull origin master를 먼저 실행해서 팀원들이 올려둔 최신 코드를 받아온 뒤 내 작업을 시작하세요!
