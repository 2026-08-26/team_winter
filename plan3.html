광주광역시 2030 청년 가구를 위한
주거 가성비 & 생활 인프라 통합 지수

실거래가만으로는 보이지 않는 "살기 좋은 정도"를 데이터로 수치화한다. 편의시설·상권·교통·문화 인프라를 먼저 수집·정제해 지표로 정리하고, 이를 바탕으로 자치구/동 단위로 비교할 수 있는 웹사이트를 만든다.

✓ 지역 범위: 광주광역시 ✓ 표본 동 단위 확정 ✓ 데이터 → 웹사이트 구조 확정 ◐ 카테고리 구성 재검토 예정 ◐ 표본 동 15~20개 리스트 확정 필요
01배경 및 목표

2030 1인 가구 증가와 주거비 부담 속에서, 매매·전월세 가격만으로는 주거지를 판단하기 어렵다. 대중교통·편의시설·문화 인프라까지 종합한 지수가 필요하다.

목표 — 2030이 실제로 체감하는 인프라 데이터를 수집·정제·수치화해 HL-Score를 산출하고, 청년층에게는 맞춤 주거지를, 청년주택·지자체에는 입지 데이터를 제공한다.
02데이터 수집 계획

광주광역시 5개 자치구 중 구별 상위 표본 동(구당 3~5개, 2030 인구 비중 높은 동 위주, 총 15~20개)만 수집한다.

제공 데이터 활용
  • 인구통계 — 광주 행정동별 2030 인구수, 1인 가구 비중, 인구 이동 추이
  • 아파트 실거래가 — 광주 자치구·평형별 매매/전월세 실거래가
추가 수집 — 공식 API 한정
  • 대중교통·편의시설 — Kakao 로컬 API 카테고리 검색 (편의점·마트·병원 등)
  • 문화·여가 — 공공데이터포털 전국문화시설 표준데이터
  • 실거래가 보강 — 네이버부동산 API (매물·시세, 보조 소스)
변경 사항 — 직방·에브리타임 등 커뮤니티 크롤링과 감성분석은 제외했다. 로그인 기반 크롤링 제약과 약관 리스크 때문이며, 대신 Kakao 로컬 API·공공데이터포털·국토교통부 실거래가 API 등 공식 API로만 데이터를 수집한다.

03핵심 지표

카테고리 구성(교통/상권/맛집/쇼핑/문화 등)은 실제 수집 데이터를 보고 재검토 예정이다.

HL-Score (Housing-Life Score)
HL-Score = (접근성 지수norm × 2030 선호 가중치 W) ÷ 실거래가norm

접근성 지수는 카테고리별 정규화 점수의 가중합. 가중치 W는 팀 내 간이 설문(n≈30)으로 산정 예정.

동 단위 비교 화면
자치구 카드 → 클릭 → 소속 동 히트맵(카테고리별 점수 + 종합점수)

구 단위 종합 평점과 동 단위 세부 비교를 한 화면 안에서 드릴다운으로 확인.

06결정 로그

기획 과정에서 바뀐 주요 결정 사항. 발표 때 "왜 이렇게 갔는지" 근거로도 쓸 수 있다.

Scope

지역 범위 — 전국/지역별 → 광주광역시로 축소. 4일·4인 일정에 맞는 실행 가능한 범위 확보.

Data Source

크롤링 → 공식 API — 직방·에브리타임 크롤링과 감성분석 제외. 네이버부동산 API 및 Kakao 로컬 API·공공데이터포털로 대체.

Direction

추천 목업 → 데이터 우선 구조 — 예산/출퇴근 입력 기반 추천 화면만으로는 발표 근거가 약하다고 판단, "수집 → 정제·지표화 → 웹사이트" 3단계로 재구성.

Granularity

동 단위 범위 — 전체 90여 개 행정동 대신 구별 상위 표본 동(3~5개, 2030 인구 비중 기준)으로 축소. 예상 소요시간 절반 이하로 단축.

UI

비교 화면 구조 확정 — 자치구 카드 → 클릭 시 동별 히트맵 비교로 드릴다운. 카테고리 구성만 추후 재검토.
