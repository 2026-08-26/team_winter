2030 주거 가성비 지수 (HL-Score) 프로젝트

광주광역시 핵심 거점 대상 인프라 접근성 대비 매물 가격 최적화 프로젝트

지역 범위: 광주광역시 (표본 동 15~20개) 팀 구성: 4인 팀 프로젝트 개발 기간: 4일 (일 8시간, 총 32시간)

1. 프로젝트 개요 및 기술 스택

본 프로젝트는 2030 세대의 주거 선택을 돕기 위해 "인프라 접근성"과 "실거래가/시세"를 결합한 주거 가성비 지수(HL-Score)를 산출하고 시각화하는 프로젝트입니다.


기술 스택 유지 이유: 역량 강화를 위해 Flask (.ipynb 기반) + Custom HTML/CSS/JS 대시보드 구조를 고수합니다.

  • 백엔드: Python, Flask (Jupyter Notebook 연동)
  • 프론트엔드: HTML5, CSS3, JavaScript (Fetch API 기반 동적 랜더링)
  • 데이터 처리: Pandas, NumPy, Scikit-learn (Min-Max 정규화)

2. HL-Score (House-Life Score) 산식 구체화

분자와 분모의 스케일 차이로 인한 지수 왜곡을 방지하기 위해 Min-Max Scaling (0~1 정규화)을 도입합니다.

HL-Score = [ 정규화된 인프라 접근성 점수 ] / [ 정규화된 평균 평당 시세 ]
  • 분자 (인프라 접근성 점수): Kakao Local API 활용
    • 반경 내 교통, 편의점, 카페, 문화시설 등 수치 측정 후 정규화(0~1)
    • 가중치 근거: 구글 폼 기반 2030 간이 설문(n≈30)으로 가중치 산정
  • 분모 (평균 시세): 국토교통부 실거래가 API + 네이버 부동산 API 병행
    • 지역 내 시세 정규화(0~1) 적용

3. 데이터 수집 및 범위 전략

  • 대상 지역: 광주광역시 주요 자치구 내 2030 밀집 표본 동 15~20개 선정 (스쿠프 정밀화)
  • 수집 데이터 소스:
    • 주 데이터: 국토교통부 실거래가 공개시스템 Open API
    • 보완 데이터: 네이버 부동산 API 연동 (매물 시세 보조 지표)
    • 인프라 데이터: Kakao Local API (카테고리별 검색)
  • 수정 사항: 크롤링 제약 및 짧은 개발 기간을 고려하여 웹 크롤링 및 감성 분석은 제외하고 공공/공식 API 중심으로 단순화
